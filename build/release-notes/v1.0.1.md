## What's new since 1.0.0

**Downloading**
- When a file of that name already exists at the destination, the file is now **skipped by default** instead of getting a `_1` suffix. Existing settings keep the choice already made. Skipped files get a violet **`SKIPPED`** badge.
- The window no longer freezes while files are copied. Each finished file used to rebuild both destination previews on the UI thread, which on a network share stalled the window for the whole download.
- **Free space on network shares and external disks** is now that volume's own. On macOS and Linux it used to be read from the start-up disk, so a server with hundreds of gigabytes free could refuse a download for "not enough space".

**Thumbnails**
- **Canon CRW** (EOS D30, D60, 10D, 300D, PowerShot G and S series) now shows the real preview, upright, with the capture date the camera recorded. Before, every CRW showed the same grey noise. When a CRW has no preview, the THM file beside it is used.
- **Select several files at once.** Click a thumbnail to highlight it, Shift-click to highlight a range, Cmd-click (Ctrl-click on Windows and Linux) to add or remove one. Then:
  - **Space**, or **Check** / **Uncheck** in the status bar, checks or unchecks all the highlighted files;
  - Cmd/Ctrl+A highlights everything shown, and Esc clears the highlight.

**macOS**
- Builds are now code-signed (ad hoc), which Apple silicon requires.
- Closing the window keeps the program running in the Dock, as Mac programs do. Click the Dock icon to bring it back, and press Cmd+Q to quit.
- Recovery, Preboot and the other system volumes are no longer listed as removable drives.

Every build is self-contained, so there is no .NET runtime to install. `ffmpeg` is optional and only gives video frame previews.

**macOS** — the builds are signed ad hoc, not with a Developer ID. Clear the quarantine flag once after unpacking, or macOS will report the app as "damaged":

```bash
tar xzf SparkPhotoDownloader-1.0.1-macos-arm64.tar.gz
xattr -cr "Spark Photo Downloader.app"
open "Spark Photo Downloader.app"
```

**Linux** — install the package with `sudo apt install ./spark-photo-downloader_1.0.1_amd64.deb`. Or unpack the tarball and run `./install.sh` for a per-user install that needs no root.

Checksums are in `SHA256SUMS.txt`.
